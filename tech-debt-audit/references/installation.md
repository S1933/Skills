# Installation

Install the `tech-debt-audit` directory as one skill, preserving its `references/` files. The client needs read access to the repository and write access only for `TECH_DEBT_AUDIT.md`.

Invoke it explicitly after opening the repository to audit. For a repeat audit, provide the existing report and request repeat-run mode so finding identifiers and resolved items can be reconciled.

No language-specific audit utility is mandatory. Missing optional tools must be reported as unaudited scope, not installed implicitly.
