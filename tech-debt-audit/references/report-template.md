# Report template

```markdown
# Tech Debt Audit — <repository>

## Executive summary
## Scope and methods
## Architectural mental model
## Findings

### <ID>: <title>
- Severity / confidence / effort
- Observation (path and line)
- Inference and impact
- Recommendation
- Verification / completion criteria

## Top five priorities
## Quick wins
## Intentional or false-positive concerns
## Open questions
## Unaudited scope and limitations
```

Keep observation distinct from inference. Never reproduce secret values in evidence excerpts.
