# Micro-testing

Use micro-tests to compare small wording variants before running expensive full scenarios.

1. Isolate one observed failure or rationalisation.
2. Write two or three minimal guidance variants.
3. Run the same focused prompt against each variant.
4. Prefer the shortest wording that changes behavior without creating false triggers.
5. Confirm the winner in the full positive, negative, ambiguous, and collision suite.

Micro-tests optimize phrasing; they do not replace end-to-end behavioral evaluation.
